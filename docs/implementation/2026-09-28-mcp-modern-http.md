# Outbound MCP HTTP and stdio: 2026-07-28 and 2025-11-25

The outbound MCP HTTP connector probes `server/discover` with the `2026-07-28` request envelope. A modern server advertising that revision is used without `initialize` or a session. Every later request carries protocol version, client capabilities, and client identity in `params._meta`, plus the required HTTP routing headers. The connector mirrors `x-mcp-header` tool arguments into `Mcp-Param-*` headers, including the protocol's Base64 sentinel encoding for unsafe values. Invalid annotations make that tool unavailable.

A handshake-era HTTP endpoint that rejects the probe with an unrecognized HTTP 400 or 404, or responds with a non-modern JSON-RPC error, continues through `initialize`. Weave requests `2025-11-25` and verifies the negotiated revision. Streamable HTTP accepts an optional session ID from the initialization response and sends it, with the negotiated protocol version header, on subsequent requests. Session expiry stops the connection; a tool call is never retried automatically. A recognized modern protocol error does not trigger a downgrade. Stdio probes with the same modern request before any other operation. A non-modern error, closed process, or 15-second probe timeout starts a fresh subprocess for the handshake-era initialization; caller cancellation and recognized modern errors do not trigger fallback. The deadline uses the injected time provider. Modern stdio sends metadata in each JSON-RPC request body and does not apply HTTP header annotations. Real subprocess tests cover modern stdio and a strict older peer that exits on the probe.

The installation still pins server identity, selected operation, and operation contract digest. For `2025-11-25` and `2026-07-28`, that digest includes the negotiated protocol revision alongside the tool definition; preexisting `2024-11-05` installations retain their original digest. An endpoint changing revision cannot activate or dispatch through its previous installation until its contract is reviewed and installed again. This also invalidates approval plans bound to the former digest. Probe, connection, and pre-dispatch refresh enforce the same binding. The integration path covers installation, invocation, restart recovery, disable, and upgrade rejection with loopback services. The Python Echo HTTP smoke test covers the older compatibility path.

An installed tool's `x-mcp-header` annotations expose the selected argument values to HTTP intermediaries. Base64 encoding is transport encoding, not secrecy. Operators should reject schemas that promote credentials or sensitive data into headers.

This slice implements outbound governed tools for the two most recent protocol revisions, `2026-07-28` and `2025-11-25`. A peer selecting `2024-11-05` remains accepted for existing stdio and HTTP-compatible Echo configurations, but that revision is outside the maintained window. `input_required` and task results fail as unsupported without an automatic second `tools/call`. Modern subscriptions, prompts, resources, HTTP+SSE fallback, server-initiated GET streams, resumable SSE, and client-initiated session DELETE are outside this connector's scope. Transport delivery after a timeout still has an unknown outcome; the connector never automatically retries a tool call.

Protocol reference: [MCP 2026-07-28 Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http), [stdio](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio), [versioning](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning), [2025-11-25 lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle), and [2025-11-25 transports](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports).
